# Custom garment drawings

Drop-in SVG drawings that replace the app's generated garment art, one garment type (or cut) at a time.

1. Add the SVG under the category folder (`tops/`, `bottoms/`, `hats/`, `shoes/`).
2. Register it in `manifest.json`.

The file format, a ready-to-paste ChatGPT prompt and the list of garment keys are in [`docs/garment-art-brief.md`](../../docs/garment-art-brief.md).
